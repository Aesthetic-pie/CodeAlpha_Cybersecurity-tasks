# Overview
This repo consists of all the tasks that I did during my one month internship at CodeAlpha. Each and every task I was doing as well as the finding I was doing had to be documented, so I created this repo for that.

## Valuable learning experience
* I had no idea on where to start studying cybersecurity up until this internship set up things for me. Although it didn't provide learning materials, but provided tasks, I had to properly divide my time between learning the concepts and actually applying what I have learnt.
* The first task I was assigned: *Building the Basic Network Sniffer*, required me to study networking fundamentals so that I can have an idea of the task that I will be dealing with, which made things way easier for me since I was already familiar with Python, and it was really interesting analyzing captured packets to understand their structure and content.
* The second task I was assigned: *Phishing Awareness Training*, was easier for me to understand because I was familiar with the phishing concept, but it was a matter of simplifying the concept to the people that do not know it and teaching it to them so that they can avoid being victims of phishing attacks.
* The third task I was assigned: *Secure Coding Review*, so here I had to select a programming language and an application to scan,  audit and find the vulnerabilities in it. So since I was also learning, I decided to audit a simple login authentication system. The code review was to identify insecure coding practices, address them and provide safer alternatives.
